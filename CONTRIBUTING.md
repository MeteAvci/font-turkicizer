# Contributing to Font Turkicizer

First off, thank you for considering contributing to **Font Turkicizer**! It's people like you that make the open-source community such a great place.

## How Can I Contribute?

### Reporting Bugs
*   Check the issues for similar reports.
*   If you find a new bug, open an issue with a clear description and steps to reproduce.

### Suggesting Enhancements
*   Open an issue to discuss your idea before implementing it.
*   Explain why the enhancement would be useful for the project.

### Pull Requests
1.  Fork the repo and create your branch from `master`.
2.  If you've added code that should be tested, add tests.
3.  Ensure the code style matches the existing project.
4.  Write a clear commit message.
